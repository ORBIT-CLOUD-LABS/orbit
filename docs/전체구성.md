# 클러스터 외부

## 모니터링 관련된 스펙

- EFK
- Grafana + Prometheus + Alertmanager
- Wazuh (agent는 모든 노드에 호스트 직접 설치)

## nginx

- astra 호스트 직접 배치
- 내부 입구: 서비스 이름(`<이름>.orbit-labs.space`)을 보고 넘기는 리버스 프록시. 팀원 전용(Tailscale)
  - 모니터링 VM: `wazuh-ui`, `kibana`, `grafana`(Grafana 설치 후)
  - 클러스터(예정, 클러스터 입구 경유): `argocd`, `hubble`
- 공개 입구(예정): 클러스터 앱 `ota`, `campaign`
- CDN Edge nginx와는 별개 (Edge는 클러스터 안의 Pod)

## HashiCorp Vault

- astra 호스트 직접 배치, 내부에서만 접근
- 저장할 비밀값: AWS IAM 키 (OTA 서버 → S3), RDS 비밀번호

## NAT 게이트웨이

- astra 호스트의 iptables (적용 완료)

## AWS (관리형)

- S3: 펌웨어 Origin
- RDS: DB

## 부하 발생기

- `io`, 클러스터에 넣지 않음
